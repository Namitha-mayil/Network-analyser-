About the Project

Documentation and viva preparation guide.

Project Overview

The AI-Based Network Traffic Analyzer is a cybersecurity application designed to monitor, analyze, and classify network traffic using Machine Learning techniques. The system processes network logs and predicts whether the traffic is Normal or constitutes an attack.

Project Objective

Build a web-based intrusion detection system (IDS) that uses the Logistic Regression algorithm to automatically classify traffic from the NSL-KDD dataset into five categories:

  • Normal: Safe traffic
  • DoS (Denial of Service): Attempts to shut down a machine or network.
  • Probe: Surveillance and probing to find vulnerabilities.
  • R2L (Root to Local): Unauthorized access from a remote machine.
  • U2R (User to Root): Unauthorized access to local superuser privileges.
Viva Questions & Answers

Network traffic is the amount of data moving across a network at any given time. In this project, it represents the packets of data sent between computers, which we analyze to detect anomalies.

Intrusion Detection is the process of monitoring network events and analyzing them for signs of possible incidents, violations, or imminent threats to security policies or acceptable use policies.

It is a widely used benchmark dataset for network intrusion detection. It was created to resolve issues in the older KDD'99 dataset by removing redundant records, making the evaluation of learning algorithms more accurate and objective.

Logistic Regression is a statistical method for analyzing datasets with independent variables that determine a categorical outcome. It is simple, highly computationally efficient, fast to train, easy to interpret, and performs remarkably well on linearly separable features commonly found in baseline traffic analysis, making it highly appropriate for an academic, lightweight IDS implementation.

Flask is a lightweight Python web framework. It perfectly bridges the gap between our Python-based Machine Learning model (Scikit-Learn) and the HTML/CSS/JS frontend, allowing users to interact with the trained model easily through a web browser without needing to run terminal commands.
